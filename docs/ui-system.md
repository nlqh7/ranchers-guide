# The Ranchers Guide UI System

This repository uses a small static component system. It borrows shadcn's open-code approach and React Bits' progressive-enhancement discipline without adding React, Tailwind, a package manager, or a client-side framework.

## Rules

1. Reuse an existing component before adding a page-specific class.
2. New components use semantic tokens such as `--color-surface`, `--color-action`, `--color-border`, and `--space-*`. Brand palette tokens are implementation details.
3. HTML remains meaningful without JavaScript. Motion and richer interactions are optional enhancements.
4. Every control has a visible keyboard focus state and a target of at least 44 by 44 pixels where practical.
5. Motion must respect `prefers-reduced-motion`; do not hide content before JavaScript runs.
6. One component owns one job. Do not create a second search, card, badge, notice, or button system for a new page.

## Component Catalog

| Job | Canonical selector | Allowed variants |
| --- | --- | --- |
| Primary command | `.btn` | `.btn-outline`, `.btn-compact` |
| Repeated destination | `.card` inside `.card-grid` | content and illustration variants already in shared CSS |
| Editorial warning | `.notice` | `.notice.info`, `.hotfix-notice` |
| Evidence state | `.evidence-badge` | official, verified, corroborated, reported, historical, obsolete |
| Main site search | `.site-search-form` / `.site-search-control` | English and Chinese labels only |
| Compact header search | `.nav-search-form` | generated by `assets/js/main.js` |
| Data list | `.data-table` inside `.data-table-wrap` | sortable state classes only |
| Article navigation | `.toc`, `.article-next` | none |
| Optional motion | `[data-ui-motion="lift"]` | enhancement only |

## Page Composition

- Home: primary search, current-status summary, then task-oriented destinations.
- Knowledge hub: primary search, domain groups, then evidence/method links.
- Guide: breadcrumb, answer-first introduction, table of contents when useful, sourced steps, next action.
- Database: answer-first summary, filters, data table/profiles, evidence registry.
- Tool: clear input state, result state, fallback guidance, related guide.
- Map: search and filters before the canvas; directory fallback must remain usable.

## Adding A Component

Before adding one, record its job, states, keyboard behavior, mobile constraints, and why an existing component cannot do the job. Put shared CSS in `assets/css/style.css`, shared behavior in `assets/js/`, and add a deterministic assertion to `scripts/check-ui-system.cjs` or a feature-specific check.

React Bits is a reference source, not a runtime dependency. Adapt only interactions that improve orientation or task completion. Avoid decorative text effects, perpetual animation, cursor effects, and anything that competes with guide content.

## Validation

Run `node scripts/check-all.cjs`. The UI check verifies the semantic token contract, canonical component selectors, shared stylesheet coverage, focus treatment, and reduced-motion fallback.
