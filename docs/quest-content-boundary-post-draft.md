# External Draft: The Ranchers Quest Content Check

> Draft for manual posting only. This is an original comparison of the site's evidence-backed quest records, not a copy of a review, wiki page or official announcement.

## Steam Discussion

### Title

How much quest content is currently documented in The Ranchers?

### Post

After the 0.8.10.842 update, I made a small evidence check of the quest routes players can currently identify. The useful distinction is between **quests recorded in a guide** and **the total number of quests in the game**. They are not the same thing.

The current records cover:

- Rust to Rumbling! — the vehicle route involving Victor and a Bykii terminal.
- Power to the Bench — the City Hall, electricity-contract and workbench route.
- Chicken Coop Mission — a community name for the early chicken-purchase objective; the exact tracker title is not retained.
- The roof-building objective — a descriptive label because the exact tracker title is not retained.
- Real Eggs, Real Evidence — Gigi's large-egg and return route.
- Solar panel objective — a community label for the basic ground-panel requirement.

That list is a documented starting point, not a claim that the game has only six quests or that the story is complete. Some routes may be optional, triggered later, named differently in the tracker, or not yet represented in the retained evidence.

If you have another quest, the most useful report includes:

1. The exact tracker title.
2. The build number.
3. The NPC or location that started it.
4. A screenshot of the objective or a short reproducible route.

The 0.8.10.842 update also targets some quest progression and validation failures, so update first before replaying an old workaround. If a quest still fails, report the exact objective and build rather than only saying that the quest is broken.

The evidence-backed records and their source boundaries are collected here: <https://theranchersguide.com/database/quests>
