The Ranchers 警星与投降指南

先回答：游戏里真的能投降吗？

EA 前官方设计 官方 Police District Update 明确写过玩家可以付款、投降，或者继续与警方周旋，并描述了投降可降低刑期与保释成本。

但本站尚未在当前 0.8.10.x 版本复测投降的按键、提示或触发条件。所以可以确认“官方设计里有投降”，不能凭旧公告编造当前版本该按哪个键。当前玩家画面和任务报告只确认警星、追捕、拘留与入狱仍然存在。

1-5 级警星分别代表什么？

EA 前官方设计 下表来自 2025 年 2 月官方 Police District Update。它能证明系统原本如何设计，不能证明当前版本每个细节都没有变化。

警星代码官方描述的警方行为被抓后的结果
1 级Code Green处理轻微违法，优先和平收取罚款；付款后不逮捕、不攻击。缴清罚款后继续行动。
2 级Code Green不使用致命武力，但会强烈要求玩家投降。被抓或投降都会进入拘留。
3 级Code Yellow警用无人机使用非致命的阻止手段。被抓后进入拘留，并可能服刑。
4 级Code Red获准使用轻型致命武器，尝试尽快结束追捕。在致命火力下被捕并拘留。
5 级Code Black使用重型致命武器，不惜代价结束追捕。最高强度的警方响应。

投降和被抓有什么区别？

EA 前官方设计 官方公告称，任何通缉等级都可以选择投降；主动投降的罚款和入狱天数低于被警方抓住。被抓或投降后，玩家会进入拘留室，支付罚款，并可能按罪行服刑。

当前版本操作未知：本站还没有带版本号的画面证明投降按钮在哪里、默认键位是什么，或者是否要先停车、下车或停止抵抗。看到论坛里有人给出按键时，先要求当前版本截图，不要把猜测当答案。

甩掉警察后，为什么警车还在找你？

EA 前官方设计 脱离追捕视线后并不会立刻结束：警车会继续搜索一小段时间，被重新发现就会恢复追捕。旧公告称，成功躲过搜索后会被判定为逃脱，并清除罚款、保留赃物。

公告没有给出搜索持续多少秒，也没有当前版本计时数据，因此本站不发布固定倒计时。

当前 Early Access 版本确认了什么？

  • 当前玩家报告 Gigi 大鸡蛋任务会触发警察追捕，多名玩家报告徒步逃脱路线可完成任务，见Gigi 任务攻略。
  • 当前系统 车辆被扣、My Garage 与 Car Pound 仍在当前版本使用，见车辆找回指南。
  • 待截图复核 当前玩家讨论能证明拘留和罚款仍会发生，但本站尚未获得可公开复核的投降 UI 画面。

来源与版本

五级警星、警方武力、投降惩罚和逃脱结果来自官方 Steam 新闻中心中的 “The Ranchers Police District Update”（2025-02-03）。这是发售前官方资料。当前 0.8.10.x 是否完全一致，必须靠当前版本画面继续校准。

警星常见问题

我能直接交罚款解除警星吗？

EA 前官方说明明确支持 1 级直接付款和平解决。2 级以上则描述为投降或被捕后进入拘留。当前版本界面和金额仍待复测。

警察从几星开始使用致命武器？

EA 前官方表述是 4 级 Code Red 开始使用轻型致命武器，5 级 Code Black 使用重型致命武器。当前版本尚未逐级实测。

投降到底按什么键？

目前未知。官方旧公告确认存在投降选择，但本站没有当前版本的按键或 UI 截图，因此不编造操作。
