A friend cannot join your ranch

CorroboratedCurrent-build check: 0.8.10.842Checked August 22, 2026

Answer first

Both players should update to the same current build, remain signed in to Steam, be Steam friends and appear online rather than invisible. The joining player then uses a subway station to travel to the friend's ranch. The launch hotfix fixes some failed friend-session joins, so do not troubleshoot an older build.

On this page
  1. Join checklist
  2. What each symptom suggests
  3. Save and host limits
  4. Evidence

Check these in order

  1. Match the build.Update every player to the current build, recorded here as 0.8.10.842. Do not compare menu access until each player confirms the displayed build.
  2. Keep Steam online.Solo play supports Steam Offline Mode, but co-op does not. Both players need Steam sign-in and internet access.
  3. Confirm Steam friendship.The community moderator's joining instructions require the players to be friends on Steam.
  4. Appear online.Invisible status can prevent the expected friend route from appearing. Set both accounts to an online-visible state for the test.
  5. Use the subway route.Travel through a subway station to the other player's ranch. Do not assume the game uses a conventional lobby browser or direct-IP flow.
  6. Change one condition at a time.If the join fails, record which player hosted, which player traveled, both builds and the last visible message before changing settings.

Host and save limits

The Ranchers uses a player's ranch as the session destination. Treat the host's ranch and the visitor's local progress as separate contexts. Before testing repeated joins, both players should exit normally and keep a note of who hosted. This site does not recommend moving or exchanging save files as a connection fix.

If every prerequisite is met but the session still fails, submit the exact error, both builds, Steam visibility states and whether reversing the host changes the outcome through Contribute.

Evidence and limits

The minimum build and fixed friend-session failures come from official launch notes. Steam friendship, online visibility and subway travel are also described by a Steam community moderator in a direct answer to a player. The diagnostic ordering is our editorial synthesis; it avoids unsupported router or firewall instructions.
