How to check an entry without guessing

The database is designed for a quick lookup followed by a useful next step. A missing value is kept visible rather than filled with an old Alpha number.

01

Search the player question

Use the item, NPC, quest, place or symptom you would type into a search engine. The result can jump to a named section instead of leaving you on a generic category page.

02

Read the evidence label

Official, video-observed, community-confirmed, reported and historical records are separated. Build numbers and review dates matter more than a tidy-looking table.

Read the verification method
03

Continue through the game

Use the related guide, quest or map route to act on the answer. For unresolved values, send a versioned screenshot through Contribute instead of treating a lead as a fact.
